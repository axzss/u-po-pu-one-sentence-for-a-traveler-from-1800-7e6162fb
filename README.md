One sentence, 170 characters, that explains the modern internet to a time traveler who has just stepped out of the year 1800 — using only words the traveler already owns:

> Imagine one road that joins every house on earth, where a letter from a friend far away lands upon your table in a blink, and every book ever written sits open beside it.

One picture, not a list of features: a single road joining every house on earth. The letter on the road is instant talk with anyone, anywhere — the friend far away writes, and the letter is already on your table before you can blink. The books open beside it are all of human knowledge, sitting at hand instead of locked in a distant library. Every word in the sentence — road, house, letter, friend, table, blink, book — already existed in 1800, so the traveler can hold the whole picture in his head with nothing new to learn first. No word coined after his time: no internet, no computer, no phone, no screen, nothing digital.

## Run it

```sh
node main.ts
```

Requires Node 22+. Standard library only, no network access. The program writes the single sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it to stdout.
